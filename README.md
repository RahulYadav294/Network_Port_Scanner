# Advanced Network Port Scanner

## Overview

Advanced Network Port Scanner is a Java-based cybersecurity tool that scans a target host for open TCP ports, identifies common services, and generates scan reports.

## Features

* TCP Port Scanning
* Service Detection
* Multithreaded Scanning
* Scan Report Generation
* Java Swing GUI
* Input Validation
* Scan Statistics Dashboard

## Technologies Used

* Java
* Java Swing
* Socket Programming
* Multithreading
* Git & GitHub

## How It Works

1. Enter Host/IP Address
2. Enter Start Port
3. Enter End Port
4. Click Scan
5. View Open Ports and Services
6. Review Scan Statistics
7. Export Results via Report File
